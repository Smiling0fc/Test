ViJoy Studio — SiteSettings GAS deployment
==========================================

Файл SiteSettings.gs хранит:

• выбранную Hero-коллекцию главной страницы;
• точку фокуса обложки для каждой коллекции;
• данные журнального выпуска для каждой коллекции:
  category, shootDate и location.

В текущем проекте маршруты getSiteSettings и updateSiteSettings
уже находятся в GAS/Code.gs. Code.gs менять не нужно.

Обновление действующего Apps Script
-----------------------------------

1. Откройте файл SiteSettings.gs в проекте Google Apps Script.

2. Полностью замените его содержимым файла:

   AdminGroupSettings/GAS/SiteSettings.gs

3. Сохраните проект.

4. Откройте:

   Развертывание → Управление развертываниями → Изменить

5. Выберите:

   Новая версия → Развернуть

После публикации доступны:

GET ?action=getSiteSettings

POST {
    action: "updateSiteSettings",
    heroCollectionId: "..."
}

POST {
    action: "updateSiteSettings",
    collectionHeroFocus: {
        "collection-id": {
            x: 50,
            y: 20
        }
    }
}

POST {
    action: "updateSiteSettings",
    collectionMetadata: {
        "collection-id": {
            category: "Свадьба",
            shootDate: "2026-07-18",
            location: "Нижний Новгород"
        }
    }
}

Дополнительные столбцы в листе Collections не требуются.
Файл CollectionMetadata.gs добавлять в Apps Script не нужно.
