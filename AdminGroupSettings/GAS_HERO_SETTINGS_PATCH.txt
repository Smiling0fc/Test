ViJoy Studio — Hero Settings GAS patch
======================================

Файл SiteSettings.gs теперь хранит:

• выбранную Hero-коллекцию главной страницы;
• точку фокуса обложки для каждой коллекции.

Если маршруты getSiteSettings и updateSiteSettings уже добавлены,
Code.gs менять повторно не нужно. Замените только содержимое
SiteSettings.gs и опубликуйте новую версию веб-приложения.

Для первой установки:

1. Добавьте файл SiteSettings.gs в тот же проект Google Apps Script,
   где находится Code.gs.

2. В функции doGet(e), внутри switch (action), ДО блока default,
   добавьте:

case "getSiteSettings":
    return jsonResponse({
        success: true,
        settings: getSiteSettings()
    });

3. В функции doPost(e), внутри switch (action), ДО блока default,
   добавьте:

case "updateSiteSettings":
    return jsonResponse(
        updateSiteSettings(body)
    );

4. setCollectionCover должен оставаться только в doPost(e).

5. Сохраните проект Apps Script.

6. Откройте:
   Развертывание → Управление развертываниями → Изменить

7. Выберите:
   Новая версия → Развернуть

После публикации доступны:

GET  ?action=getSiteSettings

POST {
    action: "updateSiteSettings",
    heroCollectionId: "..."
}

POST {
    action: "updateSiteSettings",
    collectionHeroFocus: {
        "collection-id": {
            x: 50,
            y: 20
        }
    }
}
